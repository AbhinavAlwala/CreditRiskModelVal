# Data Dictionary

All records in this repository are synthetic and generated by `src/data.py`.

| Field | Type | Description | Model role |
|---|---|---|---|
| `customer_id` | string | Synthetic unique borrower identifier | Identifier only |
| `observation_year` | integer | Portfolio vintage, 2022-2025 | Split / monitoring |
| `age` | integer | Borrower age in years; retained only for synthetic data realism | Non-model field |
| `annual_income` | float | Synthetic annual income | PD feature |
| `employment_years` | float | Years of employment | PD feature |
| `debt_to_income` | float | Debt-to-income ratio in [0,1] | PD feature |
| `credit_utilization` | float | Revolving utilization ratio in [0,1] | PD feature |
| `credit_history_years` | float | Length of credit history | PD feature |
| `delinquencies_2y` | integer | Recent delinquency count | PD feature |
| `inquiries_6m` | integer | Recent hard-inquiry count | PD feature |
| `exposure_at_default` | float | Synthetic exposure outstanding at default | ECL only; not PD feature |
| `loss_given_default` | float | Synthetic fractional loss severity in [0,1] | ECL only; not PD feature |
| `default_12m` | integer | Simulated 12-month default indicator | PD target |

## Important separation

`exposure_at_default` and `loss_given_default` are deliberately excluded from the PD feature list. They are used after scoring to translate borrower-level PD into expected credit loss:

`ECL = PD x EAD x LGD`
